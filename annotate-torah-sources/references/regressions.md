# Errors to prevent

- Claiming that a source equates suspicious silence with proof of a sale when it states only that delay looks like strategic silence; compare each source, e.g. מיחזי כמערים versus ודאי זבנה.
- Omitting a clause such as יודעין הבעלים ואינן מוחין while asserting the author ignores silence.
- Confusing דף/עמוד, citing a closely related but wrong dibbur, or fabricating a numbered Rambam halacha; verify precise chapter, letter, edition.
- Equating the source's phrase ״במקום שטר״ with a universal exemption from היסת; inspect opposing authorities individually.
- Mistaking an analogy or novel reconstruction for a verbatim assertion of the source.
- Treating a page's two columns as interleaved lines or counting page continuations inconsistently. Visual verification beats heuristic placement.
- Giving an added parallel as the passage actually used in the supplied notes, or saying an appendix is original language when it is the user's interpretation.
- Presenting paraphrase as a quote or silently eliding words. Document unsupported or uncertain references.
- Assuming right-aligned text is necessarily rendered with correct RTL order; inspect actual PDF including footnotes.
- Stopping after a single example or requesting further user action where the existing files suffice.
